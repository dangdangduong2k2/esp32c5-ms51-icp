# MS51 Connect 3.4.11

The three ST timing fields now have their own Cài đặt khởi động card between Thời gian hoạt động and Cài đặt nâng cao. Thời gian chờ ST uses a full row; ST LED and ST LCD share the following row. Existing permissions, number steppers, values and save behavior are retained. An empty startup card is hidden when all three fields are unavailable.

Build, lint and test APK compilation passed. Existing layout regression checks were updated but not run on a device. No server or MCU update is needed.
