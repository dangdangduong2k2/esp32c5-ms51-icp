# MS51 Connect 3.3.3

Ô LED đỏ nằm bên trái, đổi **CL** thành **Thời gian chờ**. Ô LED xanh nằm bên phải, đổi **OP** thành **Thời gian hoạt động**.

Giữ nguyên giá trị và nhấp nháy theo từng ô màu. Cài đè APK để cập nhật; không cần nạp lại C5/MS51.

Đã build, kiểm tra lint và đối chiếu chữ ký APK với bản trước. Chưa kiểm thử giao diện bản này trên điện thoại thật.
