# MS51 Connect 3.2.2

Xả đá dùng icon viên đá lạnh. Hai nút dùng cùng màu xanh `#176B9C` khi được chọn, cả lúc đang gửi và sau xác nhận. Giữ cách phản hồi tức thì của 3.2.1.

Chỉ cài đè APK; không cần nạp lại bo. Build, lint, chữ ký APK và bộ kiểm thử Android hiện có đều đạt. Đã kiểm tra preview thực từ Android với dữ liệu minh họa, không thêm kiểm thử mới cho thay đổi icon/màu.
