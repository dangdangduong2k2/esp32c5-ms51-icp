# MS51 Connect 3.3.2

Đổi hai mục **Xả đá OP tính giây** và **Hiện ST LED** trong cài đặt app từ checkbox thành ô chọn **Tắt / Bật**, cùng kiểu với các mục phía trên.

Giữ nguyên giá trị cài đặt và quyền hiện/ẩn do admin cấp. Cài đè APK để cập nhật; không cần nạp lại C5/MS51 hoặc thay đổi máy chủ.

Đã build, kiểm tra lint và đối chiếu chữ ký APK với bản trước. Chưa kiểm thử giao diện bản này trên điện thoại thật.
