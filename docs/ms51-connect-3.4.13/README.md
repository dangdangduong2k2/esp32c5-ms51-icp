1. Mật khẩu — Mật khẩu dự phòng.
2. Chu kỳ yêu cầu mật khẩu — Đơn vị chu kỳ.
3. Thời gian dự phòng — Đơn vị dự phòng.
4. Số lần nhập sai tối đa — Hiện phần chỉnh chu kỳ mật khẩu.
