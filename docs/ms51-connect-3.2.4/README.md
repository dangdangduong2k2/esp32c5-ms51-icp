# MS51 Connect 3.2.4

Tổng quan chỉ ghi **Theo dõi bộ điều khiển**. Bỏ câu **Mọi thiết bị, trong một không gian** ở sảnh, phần khẩu hiệu ở Đăng nhập/Tạo tài khoản và câu **Tinh chỉnh cho từng nhu cầu vận hành** ở Cài đặt. Màn hình chỉ giữ tiêu đề và nội dung hướng dẫn cần thiết; bỏ khoảng trống của những dòng đã xóa.

Chỉ cài đè APK; không đổi server hoặc phần mềm trên bo. Build và lint đạt. Kiểm tra source và chữ ký APK; không thêm test cho thay đổi câu chữ/giao diện.
